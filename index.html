Actionable prototype findings

Workout reordering is now gesture-only

Fail · P1A11Y-007CTRL-005

The builder still tells people to press and hold to reorder and still implements a long-press drag, but the only keyboard-operable reorder control is hidden with display:none. In runtime inspection every hidden handle retained a reorder label and tabIndex=0, yet none was rendered or focusable.

Evidenceprototype/app.js:355–356, prototype/app.js:477–539, prototype/styles.css:299. Runtime: four reorder buttons computed display:none; row labels still announced “Press and hold to reorder.”
RemediationKeep the clean header, but expose visible Move Up/Move Down actions in edit mode or an accessible menu with equivalent actions. If reordering is intentionally removed, delete the long-press implementation and stale accessibility copy.

Apple HIG: Accessibility · SwiftUI accessibility fundamentals

Set editing lost its visible affordance

Partial · P2CTRL-005

Set rows remain semantic buttons with useful labels such as “Edit set 1,” but the pen icon is hidden and no visible copy explains that tapping a set edits it. This is accessible to screen readers but less discoverable for sighted users.

Evidenceprototype/app.js:283 creates the edit buttons; prototype/styles.css:130 hides their only explicit edit icon.
RemediationAdd a short “Tap a set to edit” hint near the set list, a contextual Edit action, or another subtle non-pen affordance.

Builder and picker

  • Counter insets measured 4 px on both sides.
  • Stepper buttons measured 44×44 with contextual labels.

Workout behavior

  • Set rows measured 76 px high in accessibility mode.
  • Scoped status announced the logged set.
  • Final set used exercise-complete, then exercise-next on the next exercise.

Motion

  • Transition duration is 650 ms and purpose-bound.
  • prefers-reduced-motion disables the new exercise animations.
  • Core task completion does not depend on motion.

Modality and destruction

  • Dialog title receives focus.
  • Background is hidden from assistive navigation.
  • Delete is explicit, Cancel is available, and focus returns to the remove trigger.

Appearance

  • Light, Dark, and System preferences are exposed.
  • System appearance has a live media-query listener.
  • Contrast-safe accent text and high-contrast/transparency fallbacks remain present.
